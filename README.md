# 预报会商指令卡

大环境数据底座与数据要素产品 · 业务实战指南（一期）

## 项目愿景

接到领导关于“未来空气质量”的指令时，无论是专职、兼职、新手还是驻场人员，都不依赖定制开发，照着指令卡就能按统一标准选对数据、出对图表，并借助 AI 快速形成有依据的研判和汇报。

每张指令卡对应一条领导指令，回答五个问题：

1. **指令与意图**：领导到底要什么，最终交什么。
2. **必用数据**：用哪些数据，哪些是必选、哪些是佐证，本单位是否具备。
3. **标准图表**：按 HJ 633—2026 怎么出图出表，常见画错的地方。
4. **AI 研判**：交给 AI 的标准数据包和提示词，以及必须人工复核的事项。
5. **交付话术**：省级、地市级两种汇报口径，领导常见追问怎么答。

贯穿所有卡片的两条原则：

- **宁防漏报**：模式分歧大时，结论按中位数写，同时给出“最重可能达到”的上限情景。
- **结论后加管理含义**：持续时间长对应预警提前量，传输明显对应联动范围，峰值偏高提示核查排放。

## 适用对象

| 读者 | 典型单位 | 关注尺度 | 用法 |
| --- | --- | --- | --- |
| 省级业务人员 | 省监测中心站、省预报中心 | 全省多城市、区域传输 | 区域会商、对地市的指导意见 |
| 地市级业务人员 | 市生态环境局、市监测站 | 本市及区县、国控站点 | 预警启停、向市领导的日常汇报 |
| 驻场人员 | 在客户现场承担日常预报的公司人员 | 同所服务的客户 | 与客户业务人员用同一套卡 |

次要读者：公司实施顾问和售前可以拿它讲解产品；产品与研发可以把指令卡当作需求来源。

样板城市为陕西省西安市，试用对象为陕西省（省级）和西安市（地市级）。

## 交付成果

三件交付物出自同一份源文件，改一处，两边同步。

| 交付物 | 给谁用 | 位置 | 内容 |
| --- | --- | --- | --- |
| 指令卡网站 | 人：学习、查阅、培训 | `dist/index.html` | 全部指令卡；按领导指令、按数据、按图表三种检索入口；标准与规范页 |
| AI 技能包 | AI：替人执行 | `dist/skills/*.md` | 每张卡一份：输入格式、步骤（可直接作提示词）、输出、人工复核清单。不依赖特定大模型 |

## 目录

```
README.md         本文件
build.py          构建脚本：由源文件生成网站和技能包
src/cards.py      指令卡源文件（A2 至 C3 的全部内容，问题清单）
src/a1_legacy.html  A1 样板卡正文
src/sample_*.json 由标准数据集样例计算出的图表数据
dist/             构建产物，整体上传到静态托管即可
```

## 构建与部署

```
python3 build.py
```

只依赖 Python 3 标准库。修改 `src/cards.py` 后重新运行即可。

把 `dist` 目录整体上传到任意静态托管即可上线。页面通过地址中的 `#a1`、`#by-data` 等片段切换，不需要服务器端配置。字体从 Google Fonts 加载，国内访问慢时可改为本地字体或去掉该链接，页面会回退到系统字体。

## 依据的标准与文件

- 《环境空气质量指数（AQI）技术规定》（HJ 633—2026）：分指数限值、级别与颜色。
- 《环境空气质量标准》（GB 3095—2026）、《环境空气质量评价技术规范》（HJ 663—2026）。
- 总站预报字〔2020〕549 号、总站预报字〔2024〕73 号：预报准确率评估。
- 《陕西省重污染天气应急预案（2023年修订）》征求意见稿：省级预警条件。
- 《灞桥区重污染天气应急预案（2024年修订）》：地市级预警条件的暂用依据。
